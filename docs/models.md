# Безкоштовні моделі OpenRouter для WS10: ключ, ліміти, які моделі брати

Платного ключа в курсі немає. Кожен розробник працює зі **своїм** безкоштовним ключем OpenRouter і безкоштовними
моделями — тими, чий ID закінчується на `:free`. Тут — як отримати ключ, які налаштування перевірити, скільки
запитів доступно і які моделі брати для якої роботи.

**OpenRouter** — сервіс-посередник: один ключ і один API до сотень моделей різних постачальників. Безкоштовні моделі
мають жорсткий денний ліміт і можуть використовувати ваші запити для навчання — звідси правила нижче.

Корисні посилання: [README](../README.md) · [трек розробника](walkthrough-dev.md) ·
[набір AI-функції](../materials/ai-feature/README.md) · [гайд працівника](worker-guide.md).

## Ключ за 5 хвилин

1. Зареєструйтеся на <https://openrouter.ai> (власний акаунт; поповнювати баланс не треба).
2. Ключ: <https://openrouter.ai/settings/keys> → створити ключ. Значення показують один раз — одразу вставте його
   **лише** у `.env.local` свого репо:

   ```bash
   OPENROUTER_API_KEY=<ваш ключ>
   ```

   `.env.local` — у `.gitignore` шаблону. У `.env.example` — лише назва змінної без значення (рядок з
   `materials/ai-feature/env.example.add`).
3. Прод: Vercel → Project Settings → Environment Variables → `OPENROUTER_API_KEY` для Production (і Preview, якщо
   перевіряєте на preview). **Ніколи з префіксом `NEXT_PUBLIC_`:** такі змінні Next.js вбудовує в JavaScript для
   браузера, і ключ побачить будь-хто.
4. Перевірка без жодного запиту до моделі:

   ```bash
   npm run ai:models   # які безкоштовні моделі є сьогодні — ключ не потрібен
   npm run ai:quota    # скільки безкоштовних запитів лишилось сьогодні — потрібен ключ у .env.local
   ```

   Обидва скрипти — з набору [`materials/ai-feature/scripts/`](../materials/ai-feature/scripts/). `ai:quota` друкує
   лише три числа і ніколи — ключ.

Ключ — секрет. Не вставляйте його в чат з агентом, у промпт, в issue, у звіт чи на кадр. Агент не читає `.env*`.
Якщо ключ потрапив у git (навіть у минулий коміт) — видаліть його на <https://openrouter.ai/settings/keys> і створіть
новий: історія публічного репо вже не ваша.

## Приватність: що з вашими запитами

- Сам OpenRouter не зберігає тексти запитів і відповідей, якщо ви цього не ввімкнули. Але в постачальників моделей —
  свої правила, і для безкоштовних моделей OpenRouter виходить з того, що ендпоінт **може зберігати дані й навчатися
  на них**, якщо не підтверджено інше.
- **Тому — лише синтетичні дані.** Жодних справжніх клієнтів, імен, телефонів, адрес, сум, паролів і ключів — ні в
  golden cases, ні в живому eval, ні в тестових зверненнях на проді, ні у віртуальному працівнику.
- **Налаштування приватності:** <https://openrouter.ai/settings/privacy>. Постачальники, які зберігають дані (або чию
  політику OpenRouter не зміг підтвердити), отримують запити лише тоді, коли ввімкнено дозвіл для **безкоштовних**
  моделей на постачальників, що можуть навчатися на запитах. Якщо модель відповідає помилкою на кшталт «no endpoints
  match your data policy» — увімкніть цей дозвіл для безкоштовних моделей. Режим «лише ZDR» (zero data retention)
  не вмикайте: з ним із рекомендованих нижче моделей не лишиться жодної.
- Чи потрібен цей дозвіл саме для рекомендованих моделей, з публічних даних перевірити не вдалося: прапорці
  «навчається / зберігає» видно лише в інтерфейсі OpenRouter. Звідси правило «лише синтетичні дані» незалежно від
  налаштувань.

## Ліміти: 20 на хвилину, 50 на добу — на акаунт

| Що | Скільки | Що з цього випливає |
|---|---|---|
| Запитів до `:free` моделей за хвилину | 20 | кейси eval — по одному, з паузою (у наборі — 3 с), ніколи `Promise.all` |
| Запитів до `:free` моделей за добу | **50**, якщо за весь час куплено менше 10 кредитів; **1000** — після одноразової покупки ≥ 10 кредитів | на день: ваші спроби + один-два прогони eval + UAT + прогін PM |
| Доба | за UTC | у листопаді нова доба починається о **02:00 за Києвом** |
| Додаткові ключі чи акаунти | ліміт не збільшують | OpenRouter: «Making additional accounts or API keys will not affect your rate limits» |

- **Ліміт ділять усі, хто користується вашим застосунком на проді:** ви, PM з 10 golden cases, будь-хто з
  акаунтом. Тому живий eval розробника і приймання PM — у різні UTC-доби, а Server Action перевіряє `getClaims()` до
  виклику моделі: інакше ліміт витратить будь-хто з інтернету.
- **CI ніколи не кличе модель.** `npm test` — офлайн-реплей записаних відповідей; `npm run eval` — вручну.
- **Скільки лишилось** — `npm run ai:quota` (`GET https://openrouter.ai/api/v1/key` → `free_model_daily_requests`).
  Хвилинний ліміт цей запит не показує. `npm run eval` перевіряє залишок перед прогоном і зупиняється, якщо не
  вистачає.
- **Як виглядає 429:** HTTP 429 з тілом `{"error":{"code":429,"message":"Rate limit exceeded",…}}`. Буває й інакше:
  HTTP 200, а в тілі — помилка з кодом 429 від постачальника. Тести набору перевіряють обидва варіанти. Що робить
  продукт: показує стан з AC PM («помічник зараз недоступний…»), форма працює вручну, повтору в циклі немає
  (`maxRetries` 0–1).
- **Ланцюжок моделей не обходить денний ліміт акаунта.** Він рятує від збою чи перевантаження конкретного
  постачальника, а не від ваших 50 запитів. Чи рахується кожна спроба в ланцюжку окремим запитом, OpenRouter не
  пише — виходьте з того, що рахується.

## Які моделі брати

Список безкоштовних моделей змінюється щотижня: моделі з'являються, зникають, стають платними. Перед роботою й перед
eval — **`npm run ai:models`** (скрипт [`scripts/free-models.mjs`](../materials/ai-feature/scripts/free-models.mjs)): таблиця
сьогоднішніх `:free` моделей з колонками SO (строга JSON-схема), RF (JSON-режим) і tools (інструменти), а наприкінці —
чи всі моделі з вашого `src/lib/ai/models.ts` ще існують (код виходу 2 — якоїсь уже немає).

Рекомендації нижче — станом на 04.11.2026, з картки кожної моделі й даних OpenRouter. **Живим прогоном їх не
перевірено:** якість українською, точність дат і стійкість до ін'єкцій покаже лише ваш `npm run eval`. Жодна картка
моделі не підтверджує українську явно.

### Робота A — AI-функція в продукті (основне завдання)

Вільний текст (часто українською) → JSON за схемою; іноді зображення чи PDF. Ланцюжок у
`materials/ai-feature/src/lib/ai/models.ts` (той самий — у демо):

| Порядок | Модель | Чому | Застереження |
|---|---|---|---|
| 1 | `google/gemma-4-31b-it:free` | широка багатомовність за карткою (35+ мов «з коробки»), найкращі в цьому списку показники розбору документів, стабільна доступність | **немає `structured_outputs`:** OpenRouter може проігнорувати JSON-схему, тому поля повторено в промпті, а ворота — zod |
| 2 | `google/gemma-4-26b-a4b-it:free` | та сама родина й поведінка промпту, швидша | так само без `structured_outputs` |
| 3 | `nvidia/nemotron-3.5-super-vl:free` | єдина сильна безкоштовна модель зі **строгою JSON-схемою** (`structured_outputs`) і зображеннями; великий контекст | української немає в переліку мов картки |

- **Суддя** (LLM, що оцінює вільний текст за `rubric` у живому eval набору) — `nvidia/nemotron-3.5-super-vl:free`:
  інша родина, ніж основна Gemma. Якщо кейс віддала резервна Super VL, суддя тієї ж родини — це видно в колонці
  моделі звіту.
- **У ланцюжку — лише `:free`.** Платна модель у списку fallback оплачується за її ціною, навіть якщо перша —
  безкоштовна.
- **Завжди zod.** Непідтримуваний формат відповіді OpenRouter мовчки ігнорує, без помилки. Тому відповідь, що не
  пройшла схему, — стан помилки, а не «майже чернетка».

### Робота B — агентний цикл з інструментами (бонус, шлях 2, варіант B)

Лише для **експерименту** з Claude Agent SDK на безкоштовних моделях
([гайд працівника](worker-guide.md#шлях-2-claude-agent-sdk)). Конфігурацію задає
`materials/worker-agent-sdk/src/config.ts`:

| Клас моделі в SDK | Модель | Чому | Застереження |
|---|---|---|---|
| основна (`ANTHROPIC_DEFAULT_FABLE/OPUS/SONNET_MODEL`) | `nvidia/nemotron-3-ultra-550b-a55b:free` | найвищий «agentic index» серед безкоштовних моделей у даних OpenRouter; усі режими `tool_choice` | лише текст; без JSON-режиму; міркування ввімкнено за замовчуванням (повільніше); доступність нижча за інші |
| легка (`ANTHROPIC_DEFAULT_HAIKU_MODEL`) | `nvidia/nemotron-3.5-lightning:free` | швидка, усі режими `tool_choice` | маленька модель — для простих кроків |
| субагенти (`CLAUDE_CODE_SUBAGENT_MODEL`) і `fallbackModel` | `nvidia/nemotron-3.5-super-vl:free`, далі `google/gemma-4-31b-it:free` | інструменти, строга схема, зображення | чи спрацьовує `fallbackModel` на 429 від OpenRouter — не перевірено |

Чесно про ризики: Anthropic не підтримує маршрутизацію Claude Code на не-Claude моделі через шлюзи, а OpenRouter
гарантує роботу Claude Code лише з моделями самої Anthropic. Безкоштовних моделей Claude на OpenRouter немає. Один
запуск агента — кілька запитів до ліміту (кожен крок циклу — запит).

### Чого уникати

| Модель | Чому |
|---|---|
| `openrouter/free` | випадкова безкоштовна модель на кожен запит: результати eval не відтворити, можна отримати дуже малу модель |
| `stealth/…` (зокрема `stealth/crouton-alpha`) | «прихована» модель: постачальник може зберігати запити повністю для навчання і прибрати модель без попередження; без суфікса `:free` |
| `dots-studio/dots-3-note-preview:free` | попередня версія з датою завершення 31.12.2026; обмежений вибір інструментів |
| `recursive/flint-v1.0:free` | нова, з низькою доступністю на момент перевірки; орієнтована на кодинг |
| `nvidia/nemotron-3-nano-omni-…:free` | ендпоінт не підтримує жодного режиму `tool_choice` |
| `liquid/lfm-2.5-2.6b:free` | замала для української й агентів |
| моделі з ціною 0, але без `:free` | перевірте опис: це можуть бути генератори музики з оплатою за трек; `ai:models` позначає їх окремо |

## Пастка PDF: платний OCR за замовчуванням

Якщо в моделі немає нативного читання файлів (а в рекомендованих безкоштовних — немає), OpenRouter розбирає PDF
рушієм за замовчуванням — **`mistral-ocr`, платним** (близько $2 за 1000 сторінок). Безкоштовний рушій —
`cloudflare-ai` (PDF → текст). У наборі він закріплений у `src/lib/ai/models.ts`:

```ts
plugins: [{ id: "file-parser", pdf: { engine: "cloudflare-ai" } }]
```

Скановані PDF (картинки без тексту) краще перетворити на зображення сторінок і передати моделі з підтримкою
зображень (Gemma 4 чи Super VL).

## Коротко

- Ключ — **свій**, безкоштовний, лише на сервері; у ланцюжку — лише `:free`.
- **50 запитів на добу на акаунт**, доба — UTC (02:00 за Києвом); ліміт ділять ви, PM і всі користувачі проду.
- Дані — **лише синтетичні**: безкоштовні ендпоінти можуть навчатися на запитах.
- Схему перевіряє **zod**, а не модель; PDF — рушій `cloudflare-ai`.
- **Список змінюється** — `npm run ai:models` перед роботою; якість — лише ваш `npm run eval`.
