## Контекст

Зріз 4 додає AI-функцію: вільний текст (за потреби — PDF або фото до 1 МБ) → чернетка, яку людина перевіряє
й лише тоді зберігає. Обмеження:

- Next.js 16.4 на Vercel Hobby: функція працює до 300 с; Server Action приймає тіло до 1 МБ за замовчуванням.
- Модель — безкоштовна через OpenRouter, ключ — власний у кожного розробника. Ліміт безкоштовних моделей —
  20 запитів/хв і 50/день на акаунт (1000/день після одноразової покупки ≥ 10 кредитів); додаткові ключі
  ліміту не збільшують. Безкоштовні моделі з'являються й зникають.
- Безкоштовні ендпоінти можуть зберігати й використовувати запити для навчання → лише синтетичні дані.
- Відповідь моделі недетермінована, а CI має бути без мережі й без секретів.

## Рішення

- Нові залежності (точні версії): `ai@7.0.162`, `@openrouter/ai-sdk-provider@3.1.0`, `zod@4.6.7`, `server-only@0.0.1`.
- Виклик — `generateText` + `Output.object({ schema })` (AI SDK 7; `generateObject` застарілий).
  Схема zod (`src/lib/ai/schema.ts`) має стан `status: ok | needs_info | refused`; «невідоме» = `null`.
- Чиста функція `proposeDraft(input, model)` (`src/lib/ai/draft.ts`) отримує модель параметром;
  ключ читає лише `src/lib/ai/openrouter.ts` з `import "server-only"`. Змінна — `OPENROUTER_API_KEY`, без `NEXT_PUBLIC_`.
- Ланцюжок моделей (лише `:free`): `google/gemma-4-31b-it:free` → `google/gemma-4-26b-a4b-it:free` →
  `nvidia/nemotron-3.5-super-vl:free`; PDF — безкоштовний рушій `cloudflare-ai`.
- Людина в контурі: Server Action `requestDraft` лише повертає чернетку; запис — `confirmDraft` після перевірки
  людиною, з повторною валідацією на сервері. Обидві дії спершу перевіряють `getClaims()`.
- Перевірка якості: 10 golden cases PM. Офлайн-реплей записаних відповідей (`MockLanguageModelV4`) — у `npm test`
  (CI); живий прогін — `npm run eval` вручну, зі звітом частки успіху за моделлю в `evals/reports/`.

## Розглянуті варіанти

- Claude Agent SDK у функції Vercel — ні: SDK запускає підпроцес Claude Code (~320–342 МБ), а пакет функції
  Vercel — до 250 МБ; до того ж тут потрібен один виклик моделі, а не агентний цикл.
- Пакет `openai` з `baseURL` OpenRouter або `@openrouter/sdk` — ні: немає валідації схемою з типізованими
  помилками й тестових моделей (`MockLanguageModelV4`) в одному API.
- `openrouter/free` (випадкова безкоштовна модель) — ні: результат golden cases не відтворюється.
- Платний ключ — ні: курс використовує безкоштовні моделі; перехід на платного провайдера — заміна однієї фабрики
  в `src/lib/ai/models.ts`.

## Наслідки

- Простіше: провайдера й модель міняємо в одному файлі; CI не залежить від мережі та ліміту.
- Складніше: безкоштовна модель може зникнути або впертися в ліміт — інтерфейс показує зрозуміле повідомлення,
  а людина заповнює форму вручну. Ланцюжок перевіряємо `npm run ai:models` перед роботою.
- Записи `tests/fixtures/golden/recorded.json` треба оновлювати (`RECORD=1 npm run eval`), коли змінюється
  промпт (`DRAFT_PROMPT_VERSION`) або схема.
