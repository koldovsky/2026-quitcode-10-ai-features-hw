# Матеріали WS10

Три набори, які копіюються у ваш проєкт або в окреме репо. Кожен має власний README з розділами «що це»,
«навіщо», «як підключити», «як перевірити», і кожен перевіряється без живого виклику моделі.

| Тека | Що це | Для чого в домашці | Ключ |
|---|---|---|---|
| [`ai-feature/`](ai-feature/) | AI-функція в Next.js-застосунку з шаблону: документ → чернетка запису (structured output), людина підтверджує; golden cases з офлайн-повтором, живий eval, суддя, перевірка, що ключ лише на сервері | **основне завдання** | ваш безкоштовний ключ OpenRouter (`:free` моделі) |
| [`worker-claude-code/`](worker-claude-code/) | Віртуальний працівник, шлях 1: Claude Code як рушій — скіл, субагент-перевіряльник, скрипт, `claude -p` за розкладом | бонус | ваша підписка Claude, лише особисте використання |
| [`worker-agent-sdk/`](worker-agent-sdk/) | Віртуальний працівник, шлях 2: власна програма на Claude Agent SDK — `query()`, MCP-інструмент, хук-межа, JSON-результат з перевіркою в коді | бонус | платний ключ Anthropic (підтримується) або безкоштовна модель OpenRouter (експеримент, не підтримується) |
| [`virtual-accountant/`](virtual-accountant/) | Повний приклад патерну «віртуальний працівник на Claude Code» на вигаданих даних | приклад для читання | — |

## Як обрати шлях для бонусу

- Є підписка Claude (Pro, Max, Ultra, Team, Enterprise) → **шлях 1**: найменше коду, скіли й субагенти з коробки.
- Підписки немає або потрібна програма-сервіс → **шлях 2**. З платним ключем Anthropic він підтримується
  офіційно; з безкоштовною моделлю OpenRouter — це експеримент, який може зламатися (і це теж результат).

## Що спільне в усіх трьох

1. **Рахує й перевіряє код, модель пропонує.** Схема zod, скрипт звірки, перевіряльник у коді.
2. **Людина в контурі.** AI-функція лише заповнює чернетку; працівники лише звітують, нічого не надсилають і не платять.
3. **Межі в коді, а не тільки в промпті.** `import "server-only"`, `--permission-mode dontAsk` з вузьким allow,
   хук `PreToolUse`.
4. **Golden cases.** Набір входів з відомою правильною відповіддю: в `ai-feature/` і `worker-agent-sdk/` він
   прогоняється офлайн тестами; у `worker-claude-code/` це синтетичний місяць `data/2026-10` з двома навмисними
   помилками й відомим вердиктом.
5. **Ліміти безкоштовного рівня OpenRouter** (для `ai-feature/` і варіанта B у `worker-agent-sdk/`) — 20 запитів/хв
   і 50 на добу на акаунт: живі запуски плануйте економно.
